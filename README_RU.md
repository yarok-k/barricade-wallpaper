# Barricade Wallpaper

Rust-приложение для установки обоев рабочего стола с поддержкой Wayland и GTK Layer Shell.

## Описание

Barricade Wallpaper — это легковесное приложение, которое отображает изображение на весь экран в качестве фонового рисунка. Приложение использует:
- **GTK 3** и **gtk-layer-shell** для работы сWayland-сессиями
- **Rust** для обеспечения производительности и безопасности памяти

## Возможности

- Установка изображения в качестве обоев через командную строку
- Поддержка Wayland через GTK Layer Shell
- Автоматическое масштабирование изображения под размер экрана
- Простой CLI-интерфейс

## Установка

### Требования

- Rust 1.74+ (edition 2024)
- GTK 3.x
- GTK Layer Shell 0.7+

### Сборка

```bash
cargo build --release
```

### Запуск

```bash
cargo run -- --file /path/to/image.jpg
```

## Использование

Установить обои:

```bash
./barricade_wallpaper --file /path/to/image.jpg
```

Если приложение уже запущено, оно просто заменит текущие обои на указанные.
